1. 只提取标准中明确要求"应、必须、不小于、不大于、符合……级"的条款。

   - 原文引用：摘录关键原文
   - 置信度：高/中/低
   - 是否需人工确认：是/否
3. 无法确定的内容标记"需人工确认"，禁止猜测或编造。
4. 输出为符合指定 JSON Schema 的 JSON 对象，并附一份可读摘要表。
