# Q/AUTO 412-2026 汽车外饰冲压件阴极电泳及面漆涂装外观与性能标准

## 1. 适用范围
本标准规定了乘用车外覆盖件及支架阴极电泳底漆与面漆涂层的膜厚、外观缺陷限度及耐腐蚀性能检验要求。

## 2. 外观质量要求
2.1 涂层表面在标准 D65 光源（照度 ≥ 1000 lx）下距零件 500mm 目视检查，必须色泽均匀，不得有流挂、露底、气泡、起皱及剥落缺陷。
2.2 颗粒与缩孔判定：A 级外观面（外露面）直径 > 0.5mm 的颗粒或缩孔必须为 0 个；直径 0.2mm ~ 0.5mm 的颗粒在任意 100mm × 100mm 区域内不得超过 2 个，采用目视结合菲林对比卡检验。
2.3 色差与光泽：使用多角度分光测色仪检测，A 级面与标准色板色差 ΔE*ab 应不大于 0.8；60° 镜面光泽度应符合 85 ± 5 GU（光泽单位），使用光泽度计测量。

## 3. 涂层理化与耐候性能要求
3.1 漆膜干膜总厚度：使用磁性测厚仪或涡流测厚仪检测，电泳底漆膜厚应为 20 ~ 28 μm，复合涂层总膜厚必须不小于 90 μm。
3.2 涂层附着力：按 GB/T 9286 采用百格刀进行划格试验（间距 1mm）并用 3M 胶带撕拉后目视评定，附着力等级必须达到 0 级或 1 级（脱落面积 ≤ 5%）。
3.3 中性盐雾试验（NSS）：按 GB/T 10125 在盐雾试验箱（35±2℃，5% NaCl 溶液）中连续喷雾 720h 后，涂层表面应无起泡、无生锈，划痕处单侧扩蚀宽度必须不大于 2.0 mm（采用游标卡尺测量）。
